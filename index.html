About

A little about me

I'm Mark, a computer science student who fell for the web because you can build something real, publish it for free, and share it with anyone in the world — all with three files and a text editor.

My focus right now is front-end fundamentals: semantic HTML, modern CSS, and plain JavaScript without leaning on frameworks. I care about pages that load fast, work on a cheap phone, and can be used with a keyboard.

Outside of coursework I keep this site as a working archive. Every project I finish — code, screenshots, docs — ends up in the Files section, so I always have a backup I can download from anywhere.

This folder holds every downloadable file on the site.

FOLDERS
  projects/      ZIP archives of project source code
  certificates/  PDF certificates
  docs/          Documentation, proposals, reports

HOW TO ADD A FILE
  1. Drop the file into the right folder (via GitHub's web UI or git).
  2. Open js/data.js and add one object to the "files" array.
  3. Commit. GitHub Pages rebuilds in about a minute.

Keep individual files under 50 MB. GitHub hard-blocks anything over 100 MB.
